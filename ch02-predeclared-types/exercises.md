# Exercises
- [x] Write a program that declares an integer variable called `i` with value 20.
      Assign `i` to a floating-point variable named `f`. Print out `i` and `f`.
- [x] Write a program that declares a constant called `value` that can be assigned
      to both an integer and a floating-point variable. Assign it to an integer called `i`
      and a floating-point variable called `f`. Print out `i` and `f`.
- [ ] Write a program with three variables, one named `b` of type `byte`, one named `smallI` of type `int32`,
      and one named `bigI` of type `uint64`. Assign each variable the maximal legal value for its type;
      then add `1` to each variable. Print out their values.
